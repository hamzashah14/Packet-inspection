# Malware signatures for --signatures. One per line: <type> <name> <pattern>. Lines starting with # are comments.
#
#   payload <name> string:<text>     bytes inside one packet's payload; \xNN and \\ are escapes
#   payload <name> hex:<hex digits>  the same, written as hex (spaces allowed)
#   domain  <name> <domain>          TLS server name or HTTP Host: the domain itself or a sub-domain
#   ip      <name> <ip>[/<bits>]     either end of the connection, e.g. 203.0.113.0/24
#   ja3     <name> <32 hex digits>   TLS client fingerprint (list yours with --show-ja3)
#
# These are harmless examples, safe to use for testing.

# The EICAR antivirus test string: every antivirus product flags it, and it is not malware.

# A Windows executable header (MZ, followed by the PE magic offset bytes) sent in plain text
payload PE-Header   hex:4d5a9000 0300 0000
